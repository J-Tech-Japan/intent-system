# intent-cli 1.0 compatibility ledger

This reviewable ledger records the v0.11.1 machine-consumed baseline named by
the [1.0 compatibility promise](1.0-compatibility-promise.md). It is an
inventory, not a change to runtime behaviour.

## Reading a command row

Every row is a registered command/subcommand. Its command and flag names,
machine JSON field semantics and every machine-emitted `cause` value, exit-code
meaning, and referenced durable schema are covered under the 1.0 promise.
“Command-scoped JSON” deliberately does not invent a common envelope: a caller
uses that command's JSON shape and every `cause` value it emits;
a missing `cause` field does not acquire one by inference. The disposition is
the compatibility decision for the command surface.

## Cause-value coverage

Every `cause` value actually emitted in a machine-consumed JSON payload is covered, whether or not prose currently documents that value or this ledger lists it individually. Source emission, not prose documentation, determines coverage. For example, `topology-location-conflict` is covered because automation can receive it.
