# intent-cli 1.0 compatibility ledger

この reviewable ledger は
[1.0 compatibility promise](1.0-compatibility-promise.md) が指定する
v0.11.1 machine-consumed baseline を記録します。runtime behaviour の変更では
ありません。

## Command row の読み方

各 row は registered command/subcommand です。command/flag name、machine JSON
field semantics と machine が emit するすべての `cause` value、exit-code meaning、参照する
durable schema は 1.0 promise で covered です。「Command-scoped JSON」は common
envelope を発明しません。caller はその command の documented JSON shape と
その command が emit するすべての `cause` value を contract として扱います。存在しない `cause` field を inference
してはいけません。disposition は command surface に対する compatibility decision
です。

## Cause value の coverage

machine-consumed JSON payload で実際に emit されるすべての `cause` value は、prose がその value を現在 documented しているか、ledger が個別に列挙しているかにかかわらず covered です。coverage は prose documentation ではなく source emission で決まります。たとえば automation が受け取れる `topology-location-conflict` は covered です。
