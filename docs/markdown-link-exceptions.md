# Markdown local-link exceptions

This is the exact, expiring exception ledger for the repository-wide Markdown
link guard. An entry is permitted only when the broken local link cannot be
repaired in this repository. It must name the source file and line, reason,
owner, and expiry. Directory-wide, filetype-wide, release-notes-wide, and
ADR-wide exclusions are forbidden. Links introduced by the guard's own PR
never receive an exception.

There are no approved baseline exceptions at present.
