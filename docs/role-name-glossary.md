# Logical role-name glossary

G797 records the vocabulary transition made by G795. The canonical names are
the words used by current guide text; the retired names remain the keys below
so archived artifacts stay readable.

| Retired name (canonical through 2026-09-03) | Current canonical name |
| --- | --- |
| `design` | `architect` |
| `orchestration` | `orchestrator` |
| `implementation` | `builder` |
| `review` | `reviewer` |

The names in the left column remain valid historical keys in archived packets,
closeout records, runs logs, and consumer issues. They describe the vocabulary
of those artifacts, not a runtime/vendor requirement. The installed guide
routes remain unchanged while callers move to the canonical role names.
