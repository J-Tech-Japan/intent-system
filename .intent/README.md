# Project-Local Intent Inputs

This repository keeps project-local best-practice inputs under `.intent/`.

- `.intent/best-practices/`
  project-local guidance that `generate-from-current best-practice` can treat as a bounded knowledge base
- `.intent/model-registry/`
  project-local model descriptions that document the main seams this repo works with

These docs are intentionally narrow. They are starter inputs for reconstruction and review, not a replacement for parent intent refs or command logic.
